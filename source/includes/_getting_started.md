# Getting Started

Before you can begin consuming our API, you will need to contact **api_support@tapresearch.com** for an API token. This token will be used
 for authentication purposes described in the section below.

Use `https://www.tapresearch.com` as the base URL for all routes. There is no separate test server: you build and test your integration
in production with the same token, following the steps in [Testing your integration](#testing-your-integration).

When you are ready to go live, please follow the steps below:

1. Finish setting up your campaign: its quotas, qualifications and supplier_link.
2. Update the campaign's status to 2 (Active). An active campaign is shown to real respondents, and you will be charged for each complete.
